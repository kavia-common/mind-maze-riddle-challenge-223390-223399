# Mind Maze: The Riddle Quest (Frontend)

A responsive React-based riddle game with levels, scoring, timer, and lives. Built with a modern Ocean Professional theme and no UI framework dependency.

## Run locally

- Install: `npm install`
- Start dev server: `npm start` (opens http://localhost:3000)
- Test: `npm test`
- Build: `npm run build`

See README-MIND-MAZE.md for full details including environment variables.

## Notes

- No hardcoded secrets. Configuration via `.env` using `REACT_APP_*` variables.
- Lightweight routing implemented without extra dependencies.
- Fully responsive mobile and desktop layout.
